# Spec Delta

## ADDED Requirements

### Requirement: 有界批量发布队列任务
系统 MUST 在发布任何消息前验证完整输入；有效任务 SHALL 按原顺序发布，每批不超过 100 条且 UTF-8 序列化大小连同元数据预留不超过 256 KB。单条超过 128 KB 的消息 MUST 在任何写入前被拒绝。消息标识、版本和幂等键 MUST 保持不变。

#### Scenario: 超过消息数量上限
- **WHEN** 来源采集产生 220 条有效且单批大小未超限的任务
- **THEN** 系统分批发布全部任务，每批最多 100 条，没有遗漏或重复

#### Scenario: 多字节内容达到大小上限
- **WHEN** 未满 100 条的任务包含大量中文导致总大小超过单批上限
- **THEN** 系统按 UTF-8 字节大小提前分批

#### Scenario: 完整输入含无效或超大消息
- **WHEN** 输入中任一任务无效或单条大小超过上限
- **THEN** 发布操作失败且尚未写入任何消息

#### Scenario: 后续批次发布失败
- **WHEN** 先前批次成功而后续批次被队列拒绝
- **THEN** 系统停止后续发布并向调用者传播异常，采集去重状态与清理不推进，已发布消息继续受既有幂等机制保护
