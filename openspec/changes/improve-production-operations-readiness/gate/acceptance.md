## 验收范围与排除项

范围包括分层健康、探针隔离、任务领取门禁、队列/DLQ、逐条重放、隔离 canary、SLI/SLO/告警、稳定事件、发布回滚、保留治理、配置权限、容量成本、备份恢复及旧资产决策。

排除业务语义变更、多副本实际启用、外部 APM/Cloudflare Access 引入，以及任何未授权的生产部署、重放、清理、回滚、删除或真实数据试验。

自动验收只允许合成数据、隔离存储和无副作用 destination；真实用户数据、真实凭据、真实 URL/标题/正文及真实外部目标写入均禁止。

## 基线快照与可漂移性

- 需求记录的 2026-08-03T00:46:21Z 附近只读基线为：job `dead=224`、`deferred=93`、`done=4912`、`failed=1`、`processing=1`，DLQ `238`，replay operation `0`，D1 `8,540,160` 字节，Worker 心跳更新中。
- 上述数值只用于解释当前风险，不是验收阈值，也不得直接作为执行证据。
- 每次验收须重新冻结 `freezeAt`、部署版本、各状态计数、稳定摘要及查询条件；线上变化不等同于缺陷。
- 只读报告须记录查询前后计数/稳定摘要；发生漂移时废弃旧计划并重新冻结，不得静默沿用旧 `planHash`。

## 准入条件

1. 需求、技术设计、spec 与 tasks 已读回一致，实际提交和部署版本已冻结。
2. 实现完成适用的单元、集成、契约、组件测试，结果可复现且测试数据全为合成数据。
3. 隔离环境、替身依赖、无副作用 sink、可恢复备份及证据目录可用。
4. 所有证据先执行敏感哨兵扫描，凭据、Cookie、storage state、payload 与用户内容命中数为 0。
5. 涉及线上或浏览器 E2E 的用例已取得对应独立人工授权；未授权用例不得执行。
6. 24 小时与 14 天观察窗从明确时间点开始连续采样；历史零散记录不得拼接冒充完整窗口。

## 退出与判定条件

- `通过`：全部 P0、适用 P1/P2 用例实际执行通过，强制观察窗完整，敏感命中和真实副作用均为 0，无未解释差异。
- `有条件通过`：P0 全通过，仅非发布阻断的 P2 决策项待后续批准，且有责任人、期限和已接受残余风险；不得用于掩盖未满观察窗。
- `不通过`：任一 P0 失败，出现真实副作用、敏感泄漏、未解释差异、版本/数据被失败门禁改变，或 RTO 超过 15 分钟。
- `阻塞`：环境/证据/授权缺失，24 小时或 14 天窗口未满，告警渠道、保留期或 RPO 尚未批准且相应用例无法判定。
- 单元、集成、契约、组件、E2E 与运行时证据分别记录；低层通过不得替代高层和观察窗证据。

## P0 验收用例

### AT-P0-001 分层健康与长任务探针
- 前置/数据：隔离 Worker、六组件替身、固定长耗时浏览器 fixture；启动完整连续 24 小时观察窗。
- 步骤：启动长任务并按生产预算探测 liveness/readiness；切换五态并验证过期快照。
- 预期：探针超时数为 0；六组件状态、原因、时间、版本、`canAcceptWork` 可判定；过期状态不为 ready。
- 证据：探针原始序列、状态响应、部署版本、窗口起止及敏感扫描；窗口未满只能标记未验证。
- 自动化层级：单元+契约+组件+24 小时运行时证据；浏览器 E2E 受 AUTH-001 限制。

### AT-P0-002 依赖失效领取隔离
- 前置/数据：依赖/不依赖 browser、Mihomo、WARP 的合成任务各一组，无副作用 sink。
- 步骤：分别置依赖为未就绪，触发领取并核对已领取任务的完成、延期或租约释放。
- 预期：依赖任务不被新领取或被安全延期；无关任务正常；重复副作用与真实外部调用均为 0。
- 证据：领取决策、租约变化、稳定事件、sink 调用计数。
- 自动化层级：单元+集成+组件；不需要生产写入。

### AT-P0-003 队列分类与趋势一致性
- 前置/数据：含可执行、处理中、延迟、不可执行任务的冻结合成集及只读线上快照。
- 步骤：查询 summary/metrics，对照源数据计算数量、最老年龄、最早恢复时间和趋势。
- 预期：分类互斥且总数可对账；当前值、趋势、阈值状态、采集时间和部署版本齐全。
- 证据：查询响应、独立计算结果、freezeAt 与只读前后摘要。
- 自动化层级：集成+契约；生产仅只读。

### AT-P0-004 DLQ 全量一致性
- 前置/数据：按 freezeAt 冻结 DLQ、dead job、恢复信封和 replay 最小元数据。
- 步骤：生成报告，逐条验证七类之一且互斥，复核分类和总计。
- 预期：`unexplainedCount=0`，总量对账；异常可分类但不得伪装已解决；记录零修改。
- 证据：一致性报告、稳定 ID 摘要、查询前后摘要和只读审计。
- 自动化层级：集成+契约+生产只读核对。

### AT-P0-005 重放鉴权、dry-run 与幂等
- 前置/数据：隔离的可重放/材料缺失/幂等冲突/限速合成记录；生产执行需 AUTH-002。
- 步骤：依次无认证、只读身份、plan、篡改参数 execute、正确 execute、重复 operationKey。
- 预期：越权拒绝；plan 零写入；旧哈希 stale；正确计划只发布一次；状态和审计主体完整。
- 证据：响应、planHash、queue inbox 计数、审计状态、sink 计数及敏感扫描。
- 自动化层级：单元+集成+契约；生产真实重放未授权即阻塞，不得替代执行。

### AT-P0-006 隔离 canary 零副作用
- 前置/数据：固定合成 fixture、隔离 D1/Queue、dry-run destination，AUTH-001 已放行方可跑浏览器 E2E。
- 步骤：运行入队、领取、direct 成功、短内容拒绝、浏览器回退、归档模拟和结算。
- 预期：各分支可关联并正确结算；真实 Cubox、Flomo、坚果云、文章仓库写入均为 0。
- 证据：canary 事件链、隔离存储对账、网络/sink 调用审计、敏感扫描。
- 自动化层级：集成+隔离 E2E；当前 AUTH-001 未授权，E2E 结果为未执行。

### AT-P0-007 隔离回滚与 RTO
- 前置/数据：可恢复的合成备份、上一 Cloudflare API version、Console commit、Worker/Mihomo/WARP 不可变 digest、D1 migration 列表与双版本兼容合成数据；所有资产使用唯一 run ID。
- 步骤：先验证 manifest 隔离约束与 dry-run，再执行本地 D1 兼容契约、停止替身新 Worker、启动旧 Docker Compose 路径、健康/数据对账与 finally 清理；另注入一次中途失败验证清理。
- 预期：15 分钟内恢复旧 server/worker 关键路径，最新 migration 后仍可读取旧 Worker 写入，真实外部调用为 0，生产 Cloudflare、Sealos、数据与旧资产变化数为 0，成功或失败后隔离残留为 0。
- 证据：时间线、manifest/planHash、身份读回、migration 兼容查询、Compose 健康、稳定事件、外部调用计数、残留资源和敏感哨兵扫描。
- 自动化层级：组件+隔离 E2E；生产回滚另受 AUTH-005 限制。

## P1 验收用例

### AT-P1-001 14 天 SLI/SLO 与告警恢复
- 前置/数据：完整连续 14 天脱敏样本、候选 policy、零副作用越界注入器；外部投递阶段另需已批准渠道、责任人和窗口。
- 步骤：核对 SLI；依次验证无状态→pending→firing→recovered→无状态、pending 提前恢复、重复/并发评估；在渠道批准前检查通知替身调用；批准阈值与渠道后再演练一次越界及恢复投递。
- 预期：当前值、趋势、阈值、采集时间、版本齐全；候选状态转换可重复且去重，渠道批准前外部通知调用数为 0；获批后告警/恢复各恰一次且敏感命中为 0。
- 证据：14 天原始聚合、候选状态审计、通知替身零调用记录、批准记录、获批后通知回执和敏感扫描；窗口未满或渠道未批准时对应阶段不得通过。
- 自动化层级：单元+集成+隔离 E2E+14 天运行时证据。

### AT-P1-002 稳定事件追踪与敏感哨兵
- 前置/数据：覆盖领取、续租、延期、重试、死信、完成的合成任务及敏感哨兵串。
- 步骤：汇总 API/Worker 事件，按关联 ID 重建状态链并扫描全部产物。
- 预期：事件名符合点分规范，关联链无断点；日志、指标、告警、Console、证据敏感命中为 0。
- 证据：事件目录、重建报告、扫描范围与零命中报告。
- 自动化层级：单元+集成+契约。

### AT-P1-003 发布计划一致、失败停止
- 前置/数据：固定 release manifest、有效/无效 migration、digest、Secret 引用、备份和 canary 结果。
- 步骤：同输入 plan/dry-run；模拟各门禁失败；在隔离目标执行成功计划并读回版本。
- 预期：planHash 一致；任一预检失败时版本/数据零变化；成功证据完整脱敏且不跳步。
- 证据：计划 diff、步骤状态、前后版本/数据摘要、发布清单和扫描结果。
- 自动化层级：单元+脚本集成+隔离 E2E；生产发布/回滚受 AUTH-004/005 限制。

### AT-P1-004 保留报告与分批清理
- 前置/数据：跨 UTC 日界的合成心跳、完成任务、任务信封、DLQ、重放审计和幂等记录；清理阶段另需连续 14 天同参数 dry-run、已批准期限、可恢复备份，生产清理需 AUTH-003。
- 步骤：每日计算 7/30/90 天样本；重复与并发触发同一日 Cron；在部分窗口写入后注入失败并重跑；核对主采集、任务状态、租约和 Queue；满足清理门禁后才在隔离数据执行分批清理、中断恢复和幂等重跑。
- 预期：每个 UTC 日按 `(sampleDate, recordKind, windowDays)` 唯一键幂等 upsert，同键仅一行；部分失败不标记整日完成，重跑补齐且无重复；采集失败只留脱敏证据，主采集、任务状态、租约和 Queue 发布意图零变化且不触发删除；清理仅处理已批准范围并可中断对账。
- 证据：UTC 时间边界、每日样本与唯一键查询、并发/重复触发记录、失败注入与重跑对账、任务/租约/Queue 前后摘要、14 天报告、批准记录和隔离清理审计。
- 自动化层级：单元+集成+隔离恢复；生产清理当前未授权。

### AT-P1-005 配置快速失败与权限隔离
- 前置/数据：缺失/误配 Secret、管理/Worker/只读身份矩阵和敏感哨兵。
- 步骤：逐项启动或调用只读、重放、清理、发布、回滚入口，检查浏览器会话退出后状态。
- 预期：误配快速失败且只显示脱敏项名；越权请求拒绝；写操作显式确认并记录审计主体。
- 证据：启动结果、HTTP 响应、权限矩阵、审计和构建/存储敏感扫描。
- 自动化层级：单元+契约+组件。

### AT-P1-006 公开契约与业务回归
- 前置/数据：既有 API、采集、分发、限速、归档回归集和固定合成期望。
- 步骤：在基线与候选版本运行同一回归并比较路径、状态码、业务结果和副作用摘要。
- 预期：公开契约与业务语义无非预期变化，数据可跨版本读取，真实外部调用为 0。
- 证据：基线/候选报告、契约 diff、兼容读取与副作用审计。
- 自动化层级：单元+集成+契约；浏览器场景受 AUTH-001 限制。

## P2 验收用例

### AT-P2-001 单副本容量与成本
- 前置/数据：无真实目标负载模型，Worker 副本固定为 1，已批准或候选容量阈值。
- 步骤：逐步提高到达率并注入长浏览器任务/代理重连，采集资源、时延、吞吐和成本趋势。
- 预期：P50/P95、到达/消化率、积压、D1/日志用量可观察并告警；不自动扩容。
- 证据：负载参数、资源时序、容量告警、成本估算和副本读回。
- 自动化层级：隔离性能测试+运行时证据；不得使用真实目标。

### AT-P2-002 多副本准入阻断
- 前置/数据：租约竞争、重复投递、副作用幂等、归档冲突、登录态隔离、故障转移合成场景。
- 步骤：逐项运行并提交扩容申请，分别模拟任一失败和全部通过。
- 预期：任一失败均阻断；全部通过仍须独立 ADR 获批，本变更保持副本 1。
- 证据：并发测试、准入决策、replica 读回和 ADR 状态。
- 自动化层级：集成+隔离并发测试+人工 ADR 门禁。

### AT-P2-003 Worker/浏览器/WARP 备份恢复
- 前置/数据：已批准 RPO、可恢复快照、隔离环境和稳定 ID/记录数基线。
- 步骤：恢复三类状态，启动门禁并运行关键合成流程，测量 RTO/RPO 并对账。
- 预期：RTO 不超过 15 分钟，数据不超 RPO，稳定 ID/记录数一致，敏感命中与真实副作用为 0。
- 证据：快照标识、恢复时间线、版本/schema、对账与扫描结果。
- 自动化层级：隔离恢复演练；RPO 未批准时只能未验证，生产恢复需单独授权。

### AT-P2-004 旧资产零删除
- 前置/数据：旧 Python、Docker 数据和部署资产精确清单、回滚窗口与备份状态。
- 步骤：只读核对清单和删除授权，生成保留/移除建议，不执行删除。
- 预期：AUTH-006 未放行时旧资产删除数和改写数均为 0，仅形成可追踪结论。
- 证据：只读清单、备份/窗口状态、建议与变更前后摘要。
- 自动化层级：只读检查+人工授权门禁。
