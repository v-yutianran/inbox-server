# [LRN-20260924-QIB] best_practice — 队列验收同时检查 Cloudflare 与 Neon inbox

**记录时间**: 2026-09-24T09:19:33+08:00
**优先级**: high
**状态**: resolved
**领域**: infra

## 摘要

Cloudflare Queue 的 backlog 为 0 不代表已暂存到 PostgreSQL inbox 的消息都被 worker 消费。

## 详情

每小时 Cron 的 00:00、01:00 UTC 两轮 scheduler 均为 done，本地测试和构建也通过；但 01:19 UTC 只读对账发现 Neon `worker_inbox` 有 10 条已到期、未生成 `worker_jobs` 的 queued 文章消息，而 Cloudflare Queue metrics 的 backlog 为 0。当前 webhook 每次只处理一次 `queue.pull()`，Cron/Queue 唤醒的并发与批次顺序可能留下已暂存但未及时消费的消息；具体触发原因尚需复现，不能仅凭此快照认定根因。

## 建议动作

生产验收同时查询 Cloudflare Queue metrics、Neon `worker_inbox` 的 due/leased 数量和最老等待时间，以及 `worker_jobs`/`worker_effects` 终态。对“Cloudflare 空、Neon due 非空”做聚焦复现，再修复唤醒或 drain 机制；修复前不要把 Queue 指标 0 记为全链路完成。
