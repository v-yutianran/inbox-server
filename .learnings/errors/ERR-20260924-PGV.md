# [ERR-20260924-PGV] PostgreSQL 集成测试版本门禁

**记录时间**: 2026-09-24T00:47:00+08:00
**优先级**: medium
**状态**: resolved
**领域**: tests

## 摘要
ServBay PostgreSQL 17.6 的 `server_version` 带发行版后缀，严格等于 `17.6` 的测试门禁误拒。

## 错误原文
```text
expected: 17.6
actual: 17.6(ServBay)
```

## 上下文
本机隔离 `inbox_queue_test` 在执行任何 schema DDL 前因版本字符串比较失败，业务并发测试未运行。

## 建议修复
用 PostgreSQL 官方数值设置 `server_version_num` 核对目标版本；17.6 对应 `170006`。修正后在同一隔离测试库重跑，1/1 通过，失败批次回滚，测试库已清理。

- 可复现: yes
