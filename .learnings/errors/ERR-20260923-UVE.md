# [ERR-20260923-UVE] uv run 误用宿主虚拟环境

**记录时间**: 2026-09-23 23:40 UTC+8
**优先级**: high
**状态**: in_progress
**领域**: infra

## 摘要
在本仓库运行 `uv run` 前未核对继承的 `UV_PROJECT_ENVIRONMENT`，导致 uv 删除并重建了 Agents Anywhere connector 的 `.venv`，而非使用本仓库 `.venv`。项目测试虽然通过，但曾触碰无关工具环境。

## 错误原文
```text
Removed virtual environment at: /Users/xinwu/Library/Application Support/Agents Anywhere/connector/.venv
Creating virtual environment at: /Users/xinwu/Library/Application Support/Agents Anywhere/connector/.venv
```

## 上下文
- 宿主环境同时设置 `UV_PROJECT_ENVIRONMENT` 和 `VIRTUAL_ENV` 指向 connector `.venv`。
- 三条 `uv run` 检查并发启动，共用错误目标；它们最终通过，但不能证明 connector 原环境已恢复。
- 本仓库原有 `.venv` 未被替换。随后直接使用 `.venv/bin/ruff`、`.venv/bin/mypy` 和 `.venv/bin/pytest` 复跑，分别通过；pytest 为 266 passed、8 warnings。
- `uv run` 还把本仓库 `uv.lock` 的 registry URL 批量改为阿里云镜像。已先将变更版本备份到 `/Users/xinwu/.backup/inbox-server/uv.lock.before-restore-20260923-2348` 并核对 SHA-256，再从固定 HEAD 恢复；最终 `uv.lock` 为 clean。

## 建议修复
在仓库调用 uv 前先核对 `UV_PROJECT_ENVIRONMENT` 与 `VIRTUAL_ENV`；若指向其他项目，显式去除继承变量或直接调用本仓库 `.venv/bin/`。不要并发运行会同步同一环境的 `uv run`。connector 原环境可能需要由其所有者复核。
