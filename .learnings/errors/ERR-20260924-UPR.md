# [ERR-20260924-UPR] Upstash REST 令牌与顶部连接令牌混淆

**记录时间**: 2026-09-24
**优先级**: medium
**状态**: resolved
**领域**: infra

## 摘要
Upstash 详情页顶部 Token 的 Copy 值用于连接区，不能直接当作 REST Token；对 REST `/ping` 使用它返回 401。

## 错误原文
```text
HTTP Error 401: Unauthorized
```

## 上下文
- 目标 Redis 的详情页同时显示顶部 Token 与 Connect → REST 代码片段，二者有独立复制按钮。
- 复制顶部 Token 后，对 HTTPS REST `/ping` 发 Bearer 请求返回 401。
- 复制 Connect → REST 片段，解析 `UPSTASH_REDIS_REST_URL` 和 `UPSTASH_REDIS_REST_TOKEN`，同一 `/ping` 返回 HTTP 200、`PONG`。
- 验证过程只输出状态码与 PONG，不回显令牌；剪贴板随后清空。

## 建议修复
REST 客户端一律从 Connect → REST 片段取得 URL 与读写 Token，先以只读 `PING` 验证，再写入 Secret Manager；不要把 `rediss://` 密码或详情页顶部连接 Token 当成 REST Token。
