# [ERR-20260924-DBX] DBX MCP 不支持迁移事务与 DDL

**记录时间**: 2026-09-24T01:30:00+08:00
**优先级**: medium
**状态**: resolved
**领域**: infra

## 摘要
DBX MCP 的会话可用于只读核对，但当前安全门禁禁止事务语句和高风险 DDL；不能用其执行版本化 schema 迁移。

## 错误原文
```text
SQL_BLOCKED: Transaction statements are not supported by MCP.
SQL_BLOCKED: High-risk SQL is disabled in DBX MCP settings.
```

## 上下文
在已保存的 Neon 连接上尝试 `BEGIN` 与 `CREATE TABLE IF NOT EXISTS`，分别被 DBX MCP 拒绝，没有修改目标库。`dbx_open_session` 返回的 session ID 调用 `dbx_execute_query` 时仍需同时传 connection ID，否则返回 `CONNECTION_NOT_FOUND`。

## 建议修复
保持 DBX 只读核对；用 `psql` 在同一数据库执行完整迁移文件，先事务回滚预检并核对无残留，再正式提交，最后用 DBX 独立读回。不要关闭 DBX 安全门禁。
