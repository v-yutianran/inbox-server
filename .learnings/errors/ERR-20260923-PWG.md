## 摘要
用户授权用 playwright-cli 读取 GCP 配置，但当前 workspace-write/approval never 会话不能写 CLI daemon 缓存；尚未打开控制台，不得将缺少浏览器证据描述为 GCP 配置不存在。

```text
EPERM: operation not permitted, open '/Users/xinwu/Library/Caches/ms-playwright/daemon/91238f9996cd4d46/gws.err'
```

## 上下文
- `playwright-cli list` 返回 no browsers；指定 gws profile 无 SingletonLock/SingletonSocket。
- `playwright-cli --s=gws open https://console.cloud.google.com/ --headed --profile=/Users/xinwu/Documents/gws-chrome-profile --browser=chromium` 在 daemon 启动阶段退出 1。
- 未新建其它 profile、未清理原会话、未更改权限或获取云端配置。

## 建议修复
由会话宿主配置浏览器所需缓存/profile 写权限和本地 IPC 权限，再恢复同一 gws 会话并读取控制台；不要用外部进程或其它 profile 绕过沙箱。CLI list 为空不等于 GCP 未配置。

## 2026-09-23 权限更新后的复核
