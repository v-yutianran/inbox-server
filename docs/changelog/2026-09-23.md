# 2026-09-23 Changelog

## 当日变更

### feat(worker)：按配置关闭 Sealos SMTP 通知

**改了什么**：

- Worker 使用 `EMAIL_NOTIFICATIONS_ENABLED` 门控 SMTP 任务，默认 `true`，仅接受 `true` 或 `false`；设为 `false` 时无论 SMTP 凭据是否存在都不连接邮件服务器。
- Sealos Worker 清单显式设为 `false`；其它未配置此开关的部署维持邮件通知默认行为。Telegram 继续独立发送，Telegram 失败时保留现有 `telegram_notification_failed` JSON warn，不发邮件回退。
- 运维手册记录开关默认值、Sealos 设置和回滚到旧镜像可能恢复邮件的风险。未新增依赖或 OpenTelemetry 信号。
