## Git 后置 ima Markdown 镜像

- `ArticleMirror` 是应用层端口；`createArticleArchiver` 仅在 Git 保存成功后调用。
- ima adapter 使用 Markdown media type 7，按官方协议执行知识库定位、重名检查、媒体创建、COS 签名 PUT 与知识导入。
- `sha256(normalizedSourceUrl)` 完成标记原子落在 `/data/ima-mirror`；重投先查标记，实现远程零请求。
- 成功事件 `article.ima_mirror.succeeded`，失败事件 `article.ima_mirror.failed`；仅记录 provider、stage、reason、result 与耗时桶。
- 生产开关保持 `false`，轮换后的 Secret、合成 Markdown 验收和真实文章全链路尚未执行。
